# 검토

새 queue 조회는 기존 worker의 계획 경로를 사용하므로 예약/AI/대조 변경 경로에 진입하지 않는다. 실제 PG에서 반복 조회 후 pipeline/model_invocation 수 보존을 검증했다. pending 실행의 원천이 바뀌어도 기존 claim ID를 보여 준다. DB/설정 조회 실패를 빈 성공 목록으로 바꾸지 않는다. 기존 worker의 상태 판정, quota, 선택 순서는 유지한다.

UI는 기존 운영 화면에 독립 영역을 추가한다. 전체 대기·원천 대기·실행 결과 확인·일일 예산과 기업 검색/상태 필터를 제공한다. 예산 날짜는 UTC, 시각 표시는 KST이며 미래 실행 시각을 만들어 내지 않는다. 버전 일치 범위는 재무 자료에 한정한다.

개인 AWS SSH 규칙의 단일 소스만 변경했고 포트 노출을 추가하지 않았다. 로컬 키 복사는 동일 호스트 소유자 전용이며 배포/리포지토리에 포함되지 않는다. 기존 미커밋 문서는 보존한다.
