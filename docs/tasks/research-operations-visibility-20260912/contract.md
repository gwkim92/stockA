# 작업 계약

사용자 요청: 로컬 직접 접속 문제를 해결하고 자동 리서치 운영 가시성 및 실제 자동화 장애를 처리한다.

범위: 개인 AWS 115623963546/us-east-1/i-029d51b163fb07b61의 기존 사용자 접속 CIDR을 현재 브라우저/로컬 공인 IP와 대조하여 좁은 /32 규칙으로 복구한다. 회사 계정 및 다른 인스턴스는 제외한다. AWS 변경은 로그인된 Chrome 콘솔에서만 수행한다. 로컬 SSH 터널과 실제 Chrome 접근을 확인한다. 자동 갱신 queue, 실패/대기 이유, UTC 일일 예산을 읽기 전용 API와 운영 화면에 표시한다. 현재 open gates의 근거를 분류하고 승인 범위의 실제 실행 장애를 복구한다.

완료 기준: 접속 복구 실제 검증; queue API는 모델 호출/예약/상태 변경 없이 실제 worker와 같은 분류를 사용; 한도/불명 결과/원천 대기의 정확한 표현; 적절한 DB/API/UI 검사와 desktop/mobile 증거; Linux CI artifact 배포와 운영 readback; 보호 데이터/기존 timer/자원 제한 보존; 인계 갱신.

경계: 원천·추천 점수/weight/benchmark/schema/실거래/모델 설정 변경 없음. 외부 알림 전송은 이번 요청에 포함하지 않는다. 성공으로 위장하거나 gate를 근거 없이 제거하지 않는다. 기존 타 작업 변경은 보존한다.
