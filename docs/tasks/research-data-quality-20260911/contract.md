# 기업 리서치 검증과 수집 데이터 품질 개선

## 요청과 완료 기준

2026-09-11 사용자 요청: NVDA·AAPL·ARM 보고서를 주장별로 검증하고 원천·비교군 문제를 수정하며 화면에 검토 상태를 표시한다. 현재 수집 데이터가 중장기 투자 분석에 충분한지 평가하고 부족한 항목을 무료로 수집할 수 있는 수단을 조사한다.

- 운영의 현재 수집 범위·관측일·결측·출처와 세 보고서 입력을 읽기 전용으로 확인한다.
- 세 보고서의 주요 수치/주장/인용을 원문과 대조해 확인·부분 확인·미확인·불일치로 기록한다. 과거 기준일 이후 원문은 당시 주장의 입증으로 사용하지 않는다.
- 재현된 코드 문제를 작고 검토 가능한 범위에서 수정하고 검토/품질 상태를 실제 화면에서 확인한다. 과거 보고서를 근거 없이 검토 통과 처리하지 않는다.
- 무료 원천은 공식 문서에서 제공 범위·갱신·키/제한·시점 이력을 확인하고 실제 읽기 표본을 확보한다. 무료 접근과 재배포 권리는 구분한다.
- 보고서·QA·review·handoff에 완료와 잔여 한계를 남긴다.

## 경계

기존 변경을 보존한다. 새 AI 생성, 추천 weight/benchmark/평가 기준 변경, schema 변경, 금융 이력 수정, 실거래, 외부 메시지 전송은 이 작업에서 수행하지 않는다. 데이터 부족은 품질 통과로 바꾸지 않는다. 새 데이터 공급자의 운영 설치·키 발급은 조사 결과와 별도 실행 범위를 구분한다.
