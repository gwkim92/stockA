# 뉴스 원천·파생 근거 일관성 복구

프로젝트 후속 작업을 계속하라는 요청에 따라, AAPL 입력 event-19/source-document-22의 원문·번역·종목 연결 불일치를 우선 처리한다.

## 범위

- 현재 데이터와 RSS 식별자/원문 갱신/번역/이벤트 연결 경로에서 원인을 확인한다.
- 재현 테스트를 만들고 확인된 원인에 한해 작게 수정한다.
- 기존 문서·추천·점수·보유·성과 이력을 보존한다. 수정 이후 상태를 과거 지식으로 재해석하지 않는다.
- 운영 데이터 교정은 구체적인 대상·보존본·변경 전후를 준비해 실행 범위와 권한을 판단한다. 추가 유료/AI 호출이나 실거래, weight·평가 기준 변경은 포함하지 않는다.
- 다음 독립 과제는 전체 추천 성과를 성과 화면에서 탐색하게 하는 것이다. 이 task는 원천 일관성에 집중한다.

## 완료 기준

- 잘못된 원천과 번역/종목 연결이 생긴 원인이 재현된다.
- 같은 오류 재발 방지와 재수집의 멱등성 검사가 통과한다.
- 기존 기록 보존, 실제 운영 교정 여부와 미검증 범위를 각각 명시한다.
- contract/plan/qa/review/handoff가 다음 실행에 필요한 수준으로 갱신된다.
