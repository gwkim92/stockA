# 변경 검토

- calendar 목표일과 마지막 거래일의 불일치를 기존 감사의 ±7일 outcome 연결 정책으로 통일했다. benchmark, 수익률 계산, 추천 weight, 평가 기간·기준을 변경하지 않았다.
- scheduled backfill만 기존 결과 보존 모드를 사용한다. 후보 제외와 DB conflict 갱신 방지를 함께 적용한다. 수동 bootstrap의 기존 갱신 동작은 유지한다.
- 역사 성과는 현재 universe_version에서 분리하며 30/90/180/365일을 batch×horizon 20개씩 처리한다. daily AI가 실패해도 먼저 수행되는 단계로 이동했다.
- 가상 검증 입력 자격과 성과 측정 완료를 구분한다. 목록·상세는 같은 순수 정책을 사용하며 source/thesis/score/evidence 결손을 차단한다. 상세의 추가 전문 검토 주의와 입력 자격은 별도 표시다. 주문은 계속 false다.
- 리서치는 전체 원천을 중간 절단하지 않고 완전한 record만 고른다. 필수 thesis가 큰 경우 실패하고 제외 건수는 hash와 저장된 위험 문구에 반영한다. 새 프롬프트는 원천 지표·기간·ID에 연결한 주장과 사업 촉매/다음 관측을 요구한다. 이 요구만으로 내용 정확성을 검증했다고 주장하지 않는다.
- 과거 데이터는 소급 변경하지 않는다. fallback/AI/unknown 생성 경로, 구조 확인, 내용 검토 미기록을 공개하고 원천 문서 접근을 제공한다.
- market_breadth를 fundamental_quality로 표시하던 대체를 제거했다. 가격 7일 수집 기준은 유지하면서 실시간 최신성으로 오해하지 않도록 판정 의미와 시차를 노출했다.
