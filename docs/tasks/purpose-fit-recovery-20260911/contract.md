# 투자 판단 운영 복구

사용자는 프로젝트 목적 적합성 평가 후 전체 후속 작업을 계속 진행하도록 요청했다.

## 목표와 범위

1. 과거 추천 성과의 미처리 원인을 수정하고, 현재 판단과 실행 라우터의 범위를 일치시킨다.
2. 기업 리서치가 실제 생성 경로와 근거의 검증 수준을 표시하고, 기업별 주장·반대 근거·확인 조건을 검토할 수 있도록 한다.
3. 목록·상세의 가상 검증 허용 상태와 자료 최신성·지표 의미를 일치시킨다.
4. 변경된 판단과 다음 확인 사항을 화면에서 읽고 원천으로 확인할 수 있도록 한다.

기존 추천 weight, benchmark, 평가 기간·표본 기준, 실거래와 자동 주문 경계는 유지한다. 시크릿·과금·배포 환경 설정은 바꾸지 않는다. 기존 운영 배포 절차를 사용하며 배치 재실행은 대상·중복·입력과 보호 경계를 먼저 확인한다.

## 완료 기준

- 원인과 회귀 재현이 기록되고 영향 범위 테스트가 통과한다.
- 처리 가능한 과거 성과가 저장되거나 구체적인 차단 사유로 설명된다. 이미 기록된 성과는 임의 덮어쓰기하지 않는다.
- 동일 추천의 목록·상세가 같은 사용 경계를 반환한다.
- 자료 존재와 최신성, 형식 충족과 내용 검토, AI와 fallback의 차이가 실제 화면에 나타난다.
- 기업 리서치 표본은 실제 호출·저장·화면 결과로 확인하며 문장 수를 품질로 간주하지 않는다.
- 로컬, 통합·CI, 운영 배포, 운영 검증 수준을 각각 기록한다.
