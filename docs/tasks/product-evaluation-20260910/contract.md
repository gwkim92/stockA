# 전체 기능·화면 평가

## 목적과 범위

2026-09-10 현재 배포된 stockA를 실제 사용자 관점에서 평가한다. 대상은 리서치 홈, 시장·테마·뉴스, 기업·추천·근거 상세, 보유 검토, 성과·페이퍼 검증, 검토 노트, 데이터·AI·거래 안전·보완 작업 화면이다. 데스크톱 1440x1000과 모바일 390x844에서 주요 페이지와 대표 상세/검색/필터/이동 흐름을 점검한다.

## 완료 기준

- 실제 탐색으로 경로·상태 목록을 만들고 점검 여부와 미확인 범위를 기록한다.
- 기능, 데이터 최신성·일관성, 사용자 동선, 정보 구조, 가독성, 접근성, 반응형, 성능을 구분한다.
- 결함마다 실제 관찰, 재현 순서, 화면/API 증거, 사용자 영향, 우선순위와 개선안을 기록한다.
- 주요 정상 흐름과 긍정적 결과도 남긴다. 코드·테스트·운영 상태를 서로 다른 증거로 취급한다.
- report.md, qa.md, handoff.md를 최종 판단과 후속 작업이 가능하도록 갱신한다.

## 작업 경계

이번 요청은 평가다. 애플리케이션 코드, 운영 설정, 투자 판단, 모델 선택, 실거래, 스케줄러를 변경하지 않는다. 기존 사용자 변경을 보존한다. 브라우저 로컬 검토 기록은 필요할 때만 명확한 테스트 값으로 생성·정리한다. 운영 DB 쓰기·AI 재실행은 평가에 필요하지 않으면 수행하지 않는다. 표본 점검으로 전 경로 또는 투자 성과의 유효성을 추정하지 않는다.

## 실행 순서

1. 운영 연결·배포 정보와 화면 경로 목록 확인.
2. 주요 리서치→기업→추천→근거→성과/보유 흐름과 검색·필터 점검.
3. 운영·AI·안전·예외/빈 상태 점검, 데스크톱·모바일 시각 증거 확보.
4. 재현 가능한 이슈와 정상 흐름 정리, 현재 CI/런타임 증거 대조.
5. 종합 판단·우선순위·미확인 범위와 후속 작업 인계.
