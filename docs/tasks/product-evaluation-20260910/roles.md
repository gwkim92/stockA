# 검토 책임

visual-qa의 전체 검토 절차가 독립적인 읽기 전용 관점을 권고하므로, 실제 브라우저 평가와 구현·테스트 검토를 분리한다. 코드 변경이나 운영 변경은 위임하지 않는다.

- 주 평가자: 브라우저 사용자 흐름, 운영 데이터 대조, 증거 수집, 최종 판단.
- 구현 검토자: 기능 구현과 검증 범위의 격차, 데이터/상태 전달 경계 검토. 전용 결과 파일만 작성.
- 시각 검토자: 수집된 현재 화면의 정보 계층, 일관성, 가독성과 모바일 문제를 독립 검토. 전용 결과 파일만 작성.

동일 코드/런타임을 바꾸지 않으며 사용자 기존 변경을 보존한다. 각 검토 결과는 최종 보고서 작성 전 주 평가자가 현재 증거와 대조한다.
