# 재무 기간 무결성

사용자 승인: 데이터 품질 개선의 다음 단계인 재무 기간 정규화를 진행한다.

## 완료 기준

- SEC 비교연도와 비달력 회계연도를 원천 표본으로 재현하고 수정한다.
- 분기 수치와 누적 수치, 표지 주식 수만 있는 날짜를 동일 재무 기간으로 혼합하지 않는다.
- 채택/제외한 수치의 concept, 기간, accession, filed, unit, 원본 fy/fp와 선택 근거를 기존 실행 이력에 보존한다.
- 기존 잘못된 값이 재수집 후 남지 않도록 원자적 저장을 검증한다. 새 정규화는 공시일을 확인하며 지정 종목에 한정할 수 있어야 한다.
- 단위 검사와 실제 임시 PostgreSQL 검증, 운영 반영 여부 및 남은 한계를 기록한다.

## 범위와 경계

첫 적용 표본은 ARM, AAPL, NVDA다. DB schema, 과거 정규화 스냅샷, 추천 점수/weight, benchmark, 보유/주문, AI 보고서 및 모델 설정은 변경하지 않는다. 분기 현금흐름이 누적으로만 제공되면 이번 단계에서는 제외 사유를 보존하고 해당 비율을 unavailable로 둔다. 다른 공시 사이의 차감으로 독립 분기값을 추정하지 않는다. 무료 공식 원천 확대와 거시 vintage 적재는 후속 단계다.
