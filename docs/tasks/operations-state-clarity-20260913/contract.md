# 운영 상태 표시 정합성

- 주말/야간의 마지막 예정 실행이 성공한 Toss 계정·미국 장중 수집은 다음 일정 대기로 표시한다. 실패·누락·실행 정체는 숨기지 않는다. America/New_York의 월~금 기존 일정만 다루며 휴장일 달력을 도입하지 않는다.
- 공유 pipeline의 시장 수집 기록은 미국 microdata 모드로 한정해 일봉 성공이 장중 성공을 대신하지 않게 한다. 기존 pipeline 요약의 개수/범위는 보존한다.
- 저장된 사후평가 결과를 수정하지 않고, needs_more_data 항목의 실제 수치 근거 유무를 읽기 화면에서 구분한다. 누적평가 수는 동일 결정의 반복 관찰을 포함한다고 명시한다.
- 주문/weight/평가 기준/스키마/AI 모델 및 할당량/수집 스케줄 설정은 변경하지 않는다. 외부 알림이나 추가 수집을 실행하지 않는다.
- 완료: 일정 경계와 실패 보존 SQL 검증, 수치 0 및 비정상값 구분 검증, 영향 범위 UI 검사와 CI, 개인 EC2 develop 배포 후 API/실제 화면/타이머 및 설정 보존 확인.
