# recommendation-weight-review-prospective-evidence-live-observation-v1 Roles

- planner: owns exact-source, environment-identity, stability, and non-goal contracts.
- implementer: builds the identity gate, legacy-surface projection, append-only runner, and CLI.
- test owner: covers wrong targets, missing relations, exact-ID enforcement, drift, secret exclusion, and write destinations.
- reviewer: verifies that a successful observation cannot be interpreted as pilot or mutation authorization.
- operator: supplies and verifies the intended database fingerprint and exact source IDs; cannot use this artifact to start trading or mutate weights.
