## 후속 판단 대상

1. 원천 미수집, 관찰기간 미성숙, 방향 불확정 상태를 사용자 문구에서 구분한다. 현재 needs_more_data는 이 차이를 설명하지 못한다.
2. 별도 평가 기준 검토 시 독립 판단 수와 날짜별 관찰 수를 구분한다. 현재 454개 성숙 행을 독립454개 투자 판단으로 해석하면 안 된다.
3. NVDA의 hold_with_thesis/hold_review가 음의 추천 outcome에서 validated로 표시된 기존 로직도 검토 대상이다. decision_family가 benchmark_drift/position_sizing이면 cautious로 분류되는 현행 조건의 결과다. 이번 원천 수집 작업에서 평가 의미를 바꾸지는 않았다.
4. Toss 계좌 읽기 job은 금요일 최신 성공이 일요일에 stale로 표시된다. 실패 이력과 휴장일 비실행을 구분하는 운영 표시 개선은 별도 범위다. 무의미한 계좌 조회로 경고를 닫지 않았다.
