# 자동 실행 계약

- 입력: 현재 UTC 날짜, 활성 추적 US 기업, 성공한 재무 수집 SHA256/기간 정책, 기존 AI 설정.
- 실행: 한 번에 최대1개, 하루5개 예약 한도. 성공한 같은 원천/정책은 건너뛴다. 다른 실행과 경합하면 DB 예약을 얻은 쪽만 생성한다.
- 보존: 모델 실패, fallback, 결과 불명, 중단 예약은 남긴다. 결과 receipt와 실제 저장 행이 일치할 때만 완료로 취급한다.
- 재실행: 새로운 원천은 별도 후보다. 같은 버전의 결과 불명 예약은 자동 재전송하지 않는다. 실패한 모델 호출과 fallback 저장이 receipt로 확인된 경우만 24시간 후 기존 하루 한도 안에서 다시 시도한다. 입력 오류/충돌/receipt 미확인은 새 입력이나 대조 전까지 재시도하지 않는다.
- 출력: 버전/예약/child run/receipt identity와 비밀 없는 상태. 원천 본문과 환경 변수는 운영 상태에 노출하지 않는다.
- 복구: 배포 전 소스/웹/설정/보호 데이터 fingerprint를 보존한다. 원천/추천/포트폴리오를 임의로 되돌리지 않는다.
