# 전체 추천 성과 조회

## 목적

보유 스냅샷/성과귀속 보고서와 무관하게 저장된 모든 추천 성과를 조회하고 추천 기록, 연결 투자 논리, 평가 시점 보존본을 대조한다.

## 범위

- 전용 읽기 API와 `/performance/recommendations` 화면. 종목, 추천일 범위, 관찰 기간, 벤치마크, 수익 방향 조회 및 안정적인 페이지 이동.
- 저장된 관측 수익률/benchmark/alpha, 실제 측정 기간, 추천 점수/행동, 추천 상세와 thesis 연결을 표시한다.
- 추천/투자 논리 현재 저장값과 평가 실행 시점의 고정 사본을 구분한다. 추천 생성 당시 불변 기록으로 오인시키지 않는다.
- 기존 30/90/180/365일 ±7일 기간 분류를 조회에만 사용하고 실제 관찰일을 함께 표시한다. 전체 목록에 서로 다른 기간/benchmark의 평균 수익률을 만들지 않는다.
- 기존 `/performance`의 보유 귀속 보고서와 평가 이력을 유지하고 탐색 링크로 연결한다.
- DB·추천/weight·benchmark·평가 기준 변경, 새 성과 계산, AI 호출, 거래는 범위 밖이다.

## 완료 기준

전체 추천의 저장 성과가 실제 API와 화면에서 조회된다. 필터/빈 결과/오류/페이지 이동과 상세 연결을 확인한다. SQL은 실제 임시 Postgres에서 검증하며 운영에서는 읽기만 한다. 기존 변경은 보존하고, 배포·실제 Chrome 검증·한계를 handoff와 QA/review에 남긴다.
