# 검토 책임

주 작업자가 모든 구현·실행·최종 판정을 맡는다. 기존 전체 평가의 구현 검토자와 화면 검토자는 visual-qa의 독립 검토 절차에 따라 읽기 전용으로 수정의 누락과 화면 회귀를 확인한다. 새로운 구현 위임은 없으며 사용자 기존 문서는 변경하지 않는다.

- 구현 검토: 재무 기간·legacy 입력 차단, 집계와 결측 의미, 테스트의 실제 경계.
- 화면 검토: 영향 화면 캡처, 페이지 집계 범위, 모바일 단계 이동, 반복 문구.
- 주 작업자: 지적별 수정/재검증, 운영 계정/소스/artifact/서비스 검증, 인계 기록.
