# 수동 연구 운영의 자동화

사용자 요청: 서비스의 수작업을 자동화하고 다음 계획을 보고한다.

## 완료 기준

- 현재 타이머·수집·분석·검증·보고서 흐름과 수동 작업을 실제 코드와 운영 상태로 분류한다.
- 수동 SEC 종목 선택·기간 교정·정규화를 상시 작업으로 옮긴다. 최신 정책 적용 여부와 마지막 정상 수집을 기준으로 대상을 순환 선택한다.
- 자동 실행은 원천 백업, 기간 검증, 중복 방지, 실패 격리, 재시도 간격과 실행 증거를 포함한다. 저장 결과가 불확실하면 재실행 대신 대조 상태를 남긴다.
- AI 보고서의 상위 5개 반복 선택을 개선하고 기존 일일 호출 범위에서 미갱신 종목도 순환 처리한다.
- 운영 화면/API에서 새 자동 작업과 결과를 확인하며 수작업을 다시 요구하지 않는지 두 번의 실행으로 검증한다.
- 완료된 자동화와 추가 개발·인증이 필요한 부분을 구분한 다음 계획을 남긴다.

## 범위

기존 개인 EC2, 무료 SEC, 기존 scheduler/backend CLI, 기존 모델 설정을 사용한다. 새 스키마, 유료 공급자, 인증 정보 변경, 추천 weight/benchmark 변경, 실거래 자동화는 도입하지 않는다. 기존 수동 pilot은 재실행하지 않고 새로운 자동 작업으로 처리한다. 원본 DB 백업은 같은 서버에만 둔다. 사람이 승인한 것으로 자동 판정하거나 AI 검사를 전체 사실 검증으로 표시하지 않는다.
