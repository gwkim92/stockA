# 디자인 적용 기록

레퍼런스 조사: ../design-reference-research-20260910/research.md. 전체 UI 복제는 하지 않았고 다음 읽기 패턴을 실제 데이터 위에 적용했다.

- Fiscal.ai / StockAnalysis: 기업 공통 헤더, 선택한 탭, 같은 열의 수치·기간·단위. 기존 전문 재무 페이지는 유지했다. 재무 요약 API에 없는 연간·분기 비교 선택은 만들지 않았다.
- Quartr: 뉴스 목록의 선택과 검색을 유지하며 저장된 발췌를 오른쪽 패널에서 대조. 다운로드 권한과 API 발췌를 구분한다. 모바일은 목록 → 상세 → 발췌 → 원래 선택으로 돌아간다.
- Linear: 홈은 보유 검토 순서와 관측된 상태 전환을 먼저 표시한다. 원래 투자 추천 순위를 재정렬하지 않는다.
- Toss: 한국어 제목과 구분선, 짧은 메뉴, 모바일 한 열. 저장 리서치의 알려진 용어는 기존 한국어 사전으로 표시한다.

## 공통 규칙

색상 원본은 apps/web/src/styles/tokens.css. 배경 #f5f5f0, 읽기 면 #fffefa, 본문 #26313b, 보조 본문 #4f5e66, 메타 정보 #626e74, 선택 #245d82 / #e9f0f2. 수익·손실·차단은 기존 의미를 보존하며 방향을 부호와 문구로도 표시한다.

제품 제목 24~28px, 본문 13~15px, 표와 메타 11~13px. 한글 글꼴은 기존 시스템 폴백을 사용하며 외부 폰트 요청을 추가하지 않았다. 숫자는 tabular-nums, 비교 값은 오른쪽 정렬한다. 중첩 카드 대신 선·간격·선택 배경으로 관계를 표시한다.

## 상태와 동작

- 기업 view, 뉴스 q/scope/item, 보유 q/scope/holding, 홈 review는 URL 상태다. 기존 기업 #company-* 링크도 해당 탭으로 연결한다.
- 탭 방향키/Home/End, native dialog의 Escape/초점 복귀, 터치와 키보드 표 스크롤을 지원한다.
- 모바일 뉴스는 목록과 상세를 동시에 세 열로 축소하지 않는다. 재무·보유 표만 내부 가로 스크롤한다.
- 원천 GET endpoint는 기존 loadReader/parseSource를 재사용한다. 잘못된 ID, 불일치 응답, 미제공 발췌, 실패를 구분하며 내부 저장 URL과 읽기 토큰은 반환하지 않는다.
- 서버 원천 요청은 현재 원천 상세와 같은 읽기 권한 경계를 사용한다. 로컬 미리보기 프록시는 GET만 제공하며 운영 자료를 세션 중 캐시한다.

## 후속 범위

시장·테마 지도와 전문 상세 전체의 정보 구조는 이번에 재설계하지 않았다. 공통 색상·셸은 적용되며 기존 깊은 경로가 유지된다. 재무 시계열 UI를 확대하려면 기간별 수치와 원천 계보를 제공하는 별도 계약이 필요하다.
