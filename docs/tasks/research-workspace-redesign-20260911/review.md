# 자체 검토

## 판정

요청한 네 가지 업무 화면의 재설계와 로컬 검증 완료. 주 에이전트가 코드·화면·실행 기록을 함께 검토했다. 별도 독립 에이전트 검토나 원격 CI를 수행했다고 주장하지 않는다.

## 확인한 경계

- 홈의 검토 순서와 후보 순위는 기존 반환 데이터에서 온다. 새 투자 점수·알림·의사결정 승인을 만들지 않았다.
- 기업의 가격·재무·ETF·원천 차단을 기존 검증된 어댑터로 읽는다. ETF에 개별 기업 가치 모델을 적용하지 않는다. 재무 표의 결측과 행별 기간을 보존한다.
- 뉴스 제목과 요약은 저장 자료다. 묶음 전체 요약이 없는 경우 이를 명시하고 실제 구성 뉴스와 연결 설명을 제공한다. 같은 설명만 정확히 중복 제거한다. rejected 근거는 과거 quality 필드가 passed여도 차단으로 표시한다.
- 원천 API는 기존 식별자 검증과 응답 대조를 재사용하며 저장 URI·토큰은 전달하지 않는다. 입력 HTML은 React 문자열로 표시한다. 브라우저는 GET만 호출한다.
- 원천 패널의 닫기·Escape·재시도와 초점 복귀, 회사 탭의 방향키·URL·기존 해시 링크, 보유 필터·날짜·집계 보존을 확인했다.
- 기존 AI 모델 조회·설정 코드는 변경하지 않았다. 메뉴에 항상 보이는 모델 설정 진입점을 추가했다.

## 남은 범위

현재 작업은 핵심 네 화면과 공통 셸·토큰이다. 시장·테마 지도, 전문 분석 전체, 데이터 운영 화면의 깊은 정보 구조는 기존 것을 유지한다. 해당 화면은 공통 변화의 정상 렌더링을 확인했으나 이번에 전면 재설계하지 않았다.

운영 배포·푸시는 수행하지 않았다. 로컬 미리보기는 운영 데이터를 세션 중 캐시해 읽으며 쓰기·모델 변경·수집·주문 실행을 제공하지 않는다. API 발췌가 없는 원문을 UI에서 새로 가져오거나 만들어 채우지 않는다. 실제 투자 성과 향상의 증거로 해석하지 않는다.
