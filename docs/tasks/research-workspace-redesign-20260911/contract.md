# 리서치 워크스페이스 재설계

## 요청과 완료 조건

사용자의 레퍼런스 조사 후 “진행해라” 요청에 따라 실제 웹 UI를 구현한다. 앞선 조사와 concept.html은 시각 참고이며 가상 데이터는 제품에 넣지 않는다.

- 기업: 공통 헤더, URL에 남는 키보드 탭, 재무 비교 표, 현재 화면에서 원천 발췌 읽기.
- 뉴스: 검색·분류·선택을 보존하는 목록과 해석 화면, 실제 저장 발췌 패널, 실패·결측 상태.
- 홈: 보유 검토와 상태 변화부터 읽는 간결한 작업 목록, 원래 추천 순위·기준일 보존.
- 보유: 같은 열로 비교하는 표, 선택 종목의 검토 맥락, 기존 필터와 집계 범위 보존.
- 공통: 종이색·먹색·절제된 파란색 토큰, 모바일과 키보드 이동, AI 모델 설정 접근 유지.

완료는 실제 코드, 타입·단위·영향 브라우저 검사, 운영 자료를 GET으로 읽는 로컬 미리보기와 캡처, QA/검토/인계 기록으로 판단한다. 공개 배포와 투자 성능 개선은 이 작업의 완료 주장에 포함하지 않는다.

## 경계

추천 weight, benchmark, 평가 표본, DB schema, 모델 설정·인증, 원천 수집, 실거래는 변경하지 않는다. 데이터 없음과 미조회·오류·0을 구분한다. 기존 전문 상세 URL은 유지한다. 다른 task의 미커밋 문서는 보존한다.
